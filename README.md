# SDC Bulk Video Downloader

A Windows desktop launcher and local download queue for video links and supported social media collections.

## Windows preview

Download the ZIP from the [Social Media Video Downloader](https://github.com/millesjethro/SDC-BULKVIDDL/releases/tag/facebook-story-preview-3), extract it, and open **Video Bulk Downloader.exe**. Keep the extracted files together. The ZIP includes the Windows launcher, Python runtime, yt-dlp, FFmpeg, and the Chrome companion.

The preview adds support for a single video from a direct Facebook Story link when the signed-in Story page exposes an MP4. Connect Facebook in the Chrome companion before adding the link. Photo Stories and complete Facebook Highlights require separate support. The preview was tested with simulated responses and a live Facebook Story.

See [README.txt](README.txt) for setup, Chrome pairing, and queue options.
